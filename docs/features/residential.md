# 免费家宽出口

很多流媒体和 AI 服务会检查 IP 的归属：机房 IP 直接拦，家庭宽带 IP 放行。PSM 可以免费给你的节点接一个**住宅宽带（家宽）出口**，只让需要的流量走它。

## 它是怎么来的

出口来自 [VPNGate](https://www.vpngate.net/)：日本筑波大学的公益 VPN 中继项目，节点由世界各地的志愿者提供，所以不收费。PSM 在它的公开名单里：

1. 逐个查询 IP 归属，**只挑真正的家庭宽带**，剔除机房 IP 和 VPNGate 自己的中继；
2. 用 openvpn 连上其中一个，建一条**只给分流流量用**的隧道；
3. 在 Xray、sing-box 或 mihomo 里加一个出口，按规则把 Netflix、ChatGPT 这类流量分过去。

## 特点

- **国家由你选**：列表里只显示真正有节点的国家，以及每个国家的节点数。
- **掉线自动换节点**：开启"掉线自动换节点"后，节点失效时自动换成**同一个国家**的另一个节点，出口国家不会悄悄变。
- **不会漏回机房 IP**：隧道断开时，命中规则的流量会直接失败，而不是改从机房 IP 出去。
- **不影响服务器本身**：隧道只用独立的路由表，服务器自己的上网、SSH 和其他节点都不受影响。
- **三个内核共用**：Xray、sing-box、mihomo 用的是同一条隧道，换家宽节点时内核配置一个字都不用改。

## 怎么开启

进入任意一个内核的菜单（Xray / sing-box / mihomo 管理）→ **路由分流管理** → **VPNGate 家宽出口**，选择：

**一键接入（扫描 → 试连 → 写出站 → 解锁规则）**

PSM 会扫描可用的家宽 IP，让你选国家，试连成功后写好出口，并加上常用的解锁分流规则。其他选项：

| 选项 | 作用 |
| --- | --- |
| 扫描可用家宽 IP | 重新拉取名单并筛选家宽节点 |
| 查看候选节点列表 | 看有哪些候选节点 |
| 手动指定候选序号连接 | 指定用哪一个节点 |
| 更换家宽节点 | 换一个节点（同一个国家） |
| 查看隧道真实出口 IP | 确认现在用的出口 IP |
| 添加常用解锁分流规则 | 一键加上 Netflix、ChatGPT 等常用规则 |
| 掉线自动换节点：开 / 关 | 开启后定时检查，掉线就换 |
| 导出 .ovpn 配置 | 把当前节点导出成 OpenVPN 配置 |
| 断开并移除家宽出口 | 断开隧道，并从内核配置里移除这个出口 |

想让更多网站走家宽，在「路由分流管理」里按域名或 [规则集](/features/unlock) 把它们分到这个出口即可。

## 需要知道的

- 节点由志愿者提供，**速度和稳定性不保证**，适合只让少量服务走，不建议让所有流量都走家宽。
- 流量会经过志愿者的机器，**不要让登录网银这类敏感流量走这个出口**。
- 解锁效果可以用主菜单「系统管理」里的流媒体和 AI 解锁检测工具验证。
