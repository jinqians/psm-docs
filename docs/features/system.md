# 系统优化与 VPS 测试

在主菜单 **1. 系统管理** 里操作：

![系统管理菜单](/images/system.zh.png){.shot}

## 系统优化

| 选项 | 作用 |
| --- | --- |
| 显示系统信息 | 系统、内核、CPU、内存、磁盘等 |
| 启用 BBR | 开启 BBR 拥塞控制，高延迟、有丢包的国际线路明显提速 |
| 应用内核参数优化 | 调整网络相关的内核参数 |
| 创建 / 删除交换空间 | 小内存 VPS 建一个 swap，避免内存不足 |
| 设置 DNS、设置时区、同步时间（NTP） | 基础系统设置 |
| 配置防火墙（仅 443 + 22） | 只放行 443 和 SSH，适合所有节点都走 [443 端口复用](/features/port-443) 的服务器 |

## VPS 测试工具

选 **VPS 测试工具**，里面集成了常用的测试脚本：

| 工具 | 用途 |
| --- | --- |
| 本机快速体检 | 快速查看本机状态 |
| 网络延迟测试、回程 / 路由追踪 | 看到各地的延迟和回程线路 |
| NodeQuality 综合测试 | 硬件、网络、IP 质量的综合报告 |
| bench.sh、YABS、LemonBench | 性能测试 |
| IP 质量检测 | IP 的类型、风险评分、是否被标记 |
| 流媒体解锁检测 | Netflix、ChatGPT 等是否可用，改出口前后各测一次 |

测试脚本来自各自的开源项目，运行时会从网上下载；YABS 这类完整测试会占用较多带宽和时间。
