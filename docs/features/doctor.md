# 诊断与自动修复

节点连不上、服务器重启后不对劲，先运行：

```bash
psm doctor
```

它会逐项检查并给出结论（正常 / 警告 / 严重 / 跳过），最后告诉你有几项可以自动修复。

![psm doctor 检查结果](/images/doctor.zh.png){.shot}

## 自动修复

```bash
psm doctor --fix
```

能安全修复的问题会直接修好，然后重新检查一遍：

| 问题 | 自动怎么修 |
| --- | --- |
| 内核服务停了 | 先校验配置，再重启；服务定义丢了会先补写 |
| 内核还在以 root 运行 | 改为以非 root 用户 `psm-core` 运行 |
| 没设置开机自启 | 重新启用 |
| 端口跳跃的转发规则丢了 | 按节点记录重建 |
| 缺 curl、jq、openssl | 自动安装；jq 太旧（1.6）会换成新版 |
| 证书快过期 | 让 acme.sh 续期 |
| 磁盘快满了 | 清理日志、超大的 PSM 日志和软件包缓存 |

配置文件本身有错误时只报告、不改动，避免把问题越改越大。`--fix` 需要 root 权限。

## 给脚本和监控用

```bash
psm doctor --json
```

输出结构化的 JSON，退出码：`0` 正常，`1` 有严重问题，`2` 参数错误。可以接到你自己的监控或定时任务里。
