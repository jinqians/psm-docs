# 中转（realm）

中转是在客户端和节点之间再加一台服务器：客户端连**中转机**，中转机把流量原样转发到**落地机**（真正运行节点的 VPS）。常见用途是用线路更好的机器做入口，或者多台落地机共用一个入口。PSM 用 [realm](https://github.com/zhboner/realm) 做端口转发。

在中转机上打开主菜单 **12. 中转管理（realm）**，第一次进入会提示安装 realm：

![中转管理菜单](/images/realm.zh.png){.shot}

## 添加一条中转规则

选 **添加中转规则**，按提示填写：

| 提示 | 例子 |
| --- | --- |
| 规则标识 | `hk-reality` |
| 本机监听端口 | `5000` |
| 落地机地址（IP 或域名） | `1.2.3.4` |
| 落地机端口 | `443`（落地机上 REALITY 节点的端口） |
| 是否同时转发 UDP | 落地是 Hysteria2、TUIC 这类 UDP 协议时选"是" |

之后客户端把节点地址改成**中转机的 IP 和本机监听端口**（上例是 `中转机IP:5000`），其余参数不变。

## 其他功能

- **修改 / 删除 / 列出中转规则**。
- **状态报告**：中转机的资源占用、网速和到落地机的延迟，可以推送到 [Telegram](/features/telegram)。
- 服务状态、重启、日志、卸载。

记得在中转机的防火墙和云服务商安全组里放行监听端口（UDP 规则也要放行 UDP）。
