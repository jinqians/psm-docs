# 备份与恢复

改配置之前留一份备份，出了问题一键恢复。PSM 更新脚本前也会自动做一次快速备份。

在主菜单 **17. 备份管理** 里操作：

![备份与恢复菜单](/images/backup.zh.png){.shot}

| 选项 | 作用 |
| --- | --- |
| 完整备份（所有组件） | 备份 PSM 管理的所有组件的配置 |
| 选择性备份 | 只备份你选的组件 |
| 从备份恢复 | 选一个备份恢复（主菜单 **18. 恢复备份** 也可以直接进入） |
| 列出备份 | 查看已有备份 |
| 启用 / 禁用自动备份 | 每天定时自动做完整备份 |

备份是 `/opt/psm/backup/` 下的 `.tar.gz` 文件。命令行也可以直接做完整备份：

```bash
psm --backup-full
```

## 换服务器用迁移

备份用来在**同一台服务器**上回退。要把节点搬到**另一台服务器**，用 [一键迁移](/features/migrate)：它会在新服务器上装好需要的组件、重建服务并改写订阅地址，比手动恢复备份省事得多。
